MAFIA NIGHT V14 — онлайн-версия (Firebase)

Как запустить:
1. Выложи папку на GitHub Pages (или любой хостинг по https), открой ссылку на телефонах.
2. Один игрок нажимает «Создать новую комнату», остальные — «Войти по коду» (код вида MN-1234) или по ссылке из «Копировать ссылку».
3. Хост выбирает размер компании и роли и нажимает «Начать игру». Свободные места займут боты.

Как это работает:
- Игра считается на устройстве хоста, остальные игроки получают состояние через Firebase Realtime Database.
- Если хост закроет или перезагрузит страницу, партия прервётся.
- Роли лежат в базе под отдельным ключом каждого игрока. Для игры с друзьями это нормально, от продвинутых читеров не защищает.
- Правила базы тестовые и действуют до 28.11.2026. После этой даты базу нужно перенастроить.

Ночь/день: ночь (ходы ролей) -> утро -> обсуждение 40 сек -> голосование 30 сек -> новая ночь.
